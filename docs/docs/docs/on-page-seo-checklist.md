# On-Page SEO Audit Checklist

A practical checklist for reviewing and improving the on-page SEO elements of a website.

## 1. Title Tag

- [ ] Every important page has a title tag.
- [ ] Title accurately describes the page content.
- [ ] Title is unique across important pages.
- [ ] Main topic or keyword is included naturally.
- [ ] Title is clear and useful to searchers.
- [ ] Avoid unnecessary keyword repetition.

## 2. Meta Description

- [ ] Important pages have meta descriptions.
- [ ] Description accurately summarizes the page.
- [ ] Description is unique where appropriate.
- [ ] Relevant keywords are included naturally.
- [ ] Description encourages users to understand the page's value.
- [ ] Avoid misleading descriptions.

## 3. Headings

- [ ] Page has a clear main heading.
- [ ] H1 describes the main topic.
- [ ] Subheadings organize the content logically.
- [ ] Headings accurately describe their sections.
- [ ] Keywords are used naturally in headings.
- [ ] Heading elements are used for structure, not just styling.

## 4. Content Quality

- [ ] Content satisfies the intended search intent.
- [ ] Information is helpful and relevant.
- [ ] Content demonstrates appropriate knowledge of the topic.
- [ ] Claims are accurate and supported where necessary.
- [ ] Content is easy to read and understand.
- [ ] Grammar and spelling are reviewed.
- [ ] Unnecessary repetition is removed.
- [ ] Content is updated when information becomes outdated.

## 5. URL Structure

- [ ] URL clearly describes the page.
- [ ] URL is readable and meaningful.
- [ ] Words are separated using hyphens.
- [ ] Avoid unnecessary parameters where possible.
- [ ] URL structure is consistent across the website.

## 6. Images

- [ ] Images are relevant to the page.
- [ ] Image filenames are descriptive where practical.
- [ ] Important images have appropriate alt text.
- [ ] Decorative images use appropriate empty alt attributes.
- [ ] Image file sizes are optimized.
- [ ] Images display correctly on mobile devices.

## 7. Internal Linking

- [ ] Page links to relevant internal pages.
- [ ] Important pages receive internal links.
- [ ] Anchor text describes the destination.
- [ ] Links help users navigate the website.
- [ ] Broken internal links are identified.
- [ ] Orphan pages are investigated.

## 8. Search Intent and Keywords

- [ ] Primary topic is identified.
- [ ] Search intent is understood.
- [ ] Relevant secondary topics are covered.
- [ ] Keywords appear naturally in the content.
- [ ] Content avoids keyword stuffing.
- [ ] Page provides useful information beyond simply repeating keywords.

## 9. User Experience

- [ ] Content is easy to scan.
- [ ] Paragraphs are readable.
- [ ] Important information is easy to find.
- [ ] Page works on mobile devices.
- [ ] Calls to action are relevant and clear.
- [ ] No intrusive elements prevent access to content.
